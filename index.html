Frequently asked questions

Do I need prior web experience?

No. You should be comfortable with basic programming — variables, loops, functions — and we build the web part from scratch.

Which editor should I use?

VS Code with the Live Server extension — the same setup we use in class.

How is the course graded?

Labs, a two-phase project, a midterm and a final. The syllabus has the details.
